# QuickClips Personalization

This theme module provides a product personalization modal with live clip preview and Gemini image-edited output.

Architecture and compatibility notes now live in `QuickClipsPersonalization/ARCHITECTURE.md`.

## UI Changes From Original

Original baseline commit: `f703355` (`Add modular theme personalization previewer with line item property sync`).

### Personalization modal updates

- Replaced the original 2-field text modal (`Primary`/`Secondary`) with:
  - a single merged style picker (`Professional 1`, `Professional 2`, etc.)
  - `Text box 1`
  - `Text box 2`
  - optional `Text box 3`
- Added style image tiles (`quickclip-style-1.jpg`, `quickclip-style-2.jpg`, `quickclip-style-3.jpg`).
- Added a dedicated preview workspace:
  - blank QuickClip surface with the base clip image
  - deterministic browser-rendered text and icon overlays inside the same preview area
- Added on-canvas object controls:
  - delete buttons on text boxes
  - rotate handles on text boxes
  - mirror and delete buttons on icons

- The modal stage preview now stays deterministic and browser-rendered instead of swapping to the Gemini-edited image output.
- Saved previews are captured from the rendered stage surface at save time so they match what the browser showed, instead of persisting the Gemini image output or rebuilding from a separate approximation pass.
- Removed the standalone Gemini result panel from the modal UI.
- Added `Generate` action between `Cancel` and `Save personalization`.
- Reworked desktop layout so preview is on the left and inputs/actions are on the right.

## Gemini Preview Server

This server handles Gemini preview generation so the API key is kept in environment variables.

### 1) Set environment variables

PowerShell example:

```powershell
$env:GEMINI_API_KEY = "YOUR_GEMINI_API_KEY"
$env:GEMINI_IMAGE_MODEL = "gemini-2.5-flash-image"   # optional (recommended)
$env:PORT = "8788"                        # optional
```

### 2) Start the server

```powershell
node QuickClipsPersonalization/gemini-preview-server.mjs
```

Or use the helper script (loads `.env` automatically):

```powershell
.\scripts\start-gemini-preview-server.ps1
```

API endpoint:

- `POST http://localhost:8788/api/personalization-preview`
- `POST http://localhost:8788/preview`
- `POST http://localhost:8788/apps/quickclips-personalization/preview`
- body: `{ "style": "Style 1", "lastName": "...", "date": "MM/DD/YYYY" }`

### 3) Connect the theme UI

The theme JS checks `window.QuickClipsPersonalization.apiUrl`.

For local testing (browser console):

```js
window.QuickClipsPersonalization = {
  apiUrl: 'http://localhost:8788/api/personalization-preview',
};
```

If `window.QuickClipsPersonalization.apiUrl` is not set, the theme defaults to:

- `/apps/quickclips-personalization/preview`

Use that default path when routing through a Shopify app proxy in production.

Note: when your storefront is loaded over `https://`, browsers block insecure
`http://localhost` calls. In that case use app proxy (`/apps/...`) or set
`window.QuickClipsPersonalization.apiUrl` to an HTTPS endpoint.
